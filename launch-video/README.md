# Fretkey launch video

A 60-second launch video (1920 × 1080, 30 fps), built with [Remotion](https://remotion.dev). It is a separate project from the app, with its own dependencies.

```bash
npm install
npm run dev          # open the editor (Remotion Studio)
npx remotion render LaunchVideo out/fretkey-launch.mp4 --codec=h264 --crf=18
npx remotion render LaunchVideoVertical out/fretkey-launch-vertical.mp4 --codec=h264 --crf=18   # 1080 × 1920, for Reels and Shorts
```

Both cuts use the same scenes. Each scene checks `useTall()` and has its own 9:16 layout, kept clear of the top and bottom of the frame where Instagram draws its buttons and caption.

## What is in here

- `src/LaunchVideo.tsx`: the eight scenes in order. Every cut falls on a bar line of the music (one bar = 72 frames).
- `src/scenes/`: one file per scene. Text, timings and colours are edited here.
- `src/theme.tsx`: the app's colours and fonts, the phone frame and the shared background.
- `public/shots/`: real screens captured from the app. Re-capture them when the app's look changes.
- `public/music.wav`: the soundtrack. It is original and generated by `node scripts/make-music.mjs`, so there is nothing to license.
- `public/fonts/`: Fraunces and Inter (SIL Open Font License), bundled so rendering needs no network.

## Facts stated in the video

Update these when they change: 236 lessons, 6 levels of theory, 4 playing tracks (`src/scenes/Numbers.tsx`), and "Level 1 is free" (`src/scenes/Cta.tsx`).
