# Fretkey launch video

A 60-second launch video (1920 × 1080, 30 fps), built with [Remotion](https://remotion.dev). It is a separate project from the app, with its own dependencies.

```bash
npm install
npm run dev          # open the editor (Remotion Studio)
npx remotion render LaunchVideo out/fretkey-launch.mp4 --codec=h264 --crf=18
npx remotion render LaunchVideoVertical out/fretkey-launch-vertical.mp4 --codec=h264 --crf=18   # 1080 × 1920, for Reels and Shorts
```

There is also a longer promo (about 84 seconds, 16:9) with a calmer soundtrack:

```bash
npx remotion render PromoVideo out/fretkey-promo.mp4 --codec=h264 --crf=18
npx remotion render PromoVideoVertical out/fretkey-promo-vertical.mp4 --codec=h264 --crf=18   # 1080 × 1920
```

Its scene order and lengths are the `PROMO_SCENES` list in `src/promo/PromoVideo.tsx`. The eight lessons it shows, with their captions, are the `LESSONS` list in `src/promo/Showcase.tsx`. Its music is `public/focus.wav`, from `node scripts/make-focus-music.mjs`.

## Narrated reels and story posters

Three 16:9 reels with an English voice-over, and three story posters (1080 × 1920 stills):

```bash
npx remotion render ReelLearn out/fretkey-reel-1-how-you-learn.mp4 --codec=h264 --crf=19
npx remotion render ReelLesson out/fretkey-reel-2-inside-a-lesson.mp4 --codec=h264 --crf=19
npx remotion render ReelBlues out/fretkey-reel-3-twelve-bar-blues.mp4 --codec=h264 --crf=19
npx remotion still PosterUsp ../brand/story-1-why-fretkey.png      # also PosterLesson, PosterJourney
```

- **The words** are in `src/reels/voice.json`, one line per segment. Each line is also shown as a caption.
- **The voice** is generated locally by [Piper](https://github.com/rhasspy/piper) with the "cori" voice (British English, female, trained on public-domain LibriVox recordings). After editing the words, run `pip install piper-tts`, download `vits-piper-en_GB-cori-medium` from the sherpa-onnx `tts-models` release on GitHub, then `PIPER_MODEL=/path/to/en_GB-cori-medium.onnx node scripts/make-voice.mjs`. It rewrites `public/vo/` and `src/reels/voice-timing.json`; every segment is as long as its recording, so the reels re-time themselves.
- **The pictures** for each line are in `src/reels/LearnReel.tsx`, `LessonReel.tsx` and `BluesReel.tsx`. The blues reel plays `public/blues.wav` (from `node scripts/make-blues.mjs`) while its twelve bars light up.
- **The posters** are in `src/reels/Posters.tsx`.

## Beginner lesson reel (9:16)

"All twelve notes", taught in full in about 80 seconds, with the keyboard and a guitar string following the voice:

```bash
npx remotion render ReelBeginner out/fretkey-reel-4-twelve-notes-vertical.mp4 --codec=h264 --crf=18
```

- **Words and captions:** `src/beginner/script.json`. `say` is spoken, `show` is the caption (`*word*` turns gold). Lists such as the letters and the count use `items` and are spoken one item per `beat`, so they are never rushed and the keys light exactly on each word. The brand is written "Fret key" in `say` so the voice stresses it as two words.
- **Voice:** [Kokoro](https://huggingface.co/hexgrad/Kokoro-82M) (Apache-2.0), voice `af_heart`, run locally. Install with `pip install kokoro-onnx`, download `kokoro-v1.0.onnx` and `voices-v1.0.bin` from the `model-files-v1.0` release of thewh1teagle/kokoro-onnx on GitHub, then `python3 scripts/make-beginner-voice.py /folder/with/those/files`. It rewrites `public/beginner/` and `src/beginner/timing.json`, and the reel re-times itself.
- **Notes:** `public/notes/45.wav` to `69.wav`, from `node scripts/make-notes.mjs`.
- **Picture:** `src/beginner/BeginnerReel.tsx`, one continuous scene; what the keyboard shows at each moment is in `keysAt`.

The two launch cuts use the same scenes. Each scene checks `useTall()` and has its own 9:16 layout, kept clear of the top and bottom of the frame where Instagram draws its buttons and caption.

## What is in here

- `src/LaunchVideo.tsx`: the eight scenes in order. Every cut falls on a bar line of the music (one bar = 72 frames).
- `src/scenes/`: one file per scene. Text, timings and colours are edited here.
- `src/theme.tsx`: the app's colours and fonts, the phone frame and the shared background.
- `public/shots/`: real screens captured from the app. Re-capture them when the app's look changes.
- `public/music.wav`: the soundtrack. It is original and generated by `node scripts/make-music.mjs`, so there is nothing to license.
- `public/fonts/`: Fraunces and Inter (SIL Open Font License), bundled so rendering needs no network.
